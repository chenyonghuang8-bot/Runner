# Runner：个人 AI 跑步教练

M1 与 M2 的本地截图流程已实现并验证：Vue 3 页面、单用户账户、个人档案、可跑日程、训练手工记录、身体反馈、私有截图、选择区域、分段识别、证据核对与确认保存。使用已确认的暖白与森林绿 UI，适配电脑和手机。

当前产品只提供跑步课程：能力评估、轻松跑/长跑/符合证据条件的受控跑、完整周期与恢复安排，以及身体反馈、天气和日程变化后的调整提案。力量入口、条件表单和记录功能已停用；旧力量数据保留在数据库、导出和备份中，不参与新课程规划。模型仅生成草稿，后端校验通过且用户确认后生效。每周按档案次数安排，相邻跑步至少隔一个完整日，跨周同样遵守，不追补漏练。

默认使用明确标记的模拟服务。DeepSeek-V4.1-Flash（deepseek-flash）截图、教练对话与周期接口已经接入，历史真实联调见阶段文档；本次跑步专用模式通过合成接口与本地规则回归，尚未再次调用真实 AI 验收。截图读数与个人计划仍须本人核对。天气已接通城市参考点预报，提醒仍为本地模拟，不发送微信。

AI 定位为跑步训练教练，依据已确认事实和可审查规则解释课程；不虚构资质、医学诊断或成绩保证。数值上限与阶段规则未经人工专业审阅，数据不足时保留问题与恢复待核对项。

## 本地启动

需要 Node.js 22.12+ 和 Python 3.11。首次安装：

```bash
python3 -m venv backend/.venv
backend/.venv/bin/python -m pip install -r backend/requirements.lock
npm ci --prefix frontend
```

启动前后端和数据库迁移：

```bash
./scripts/dev.sh
```

打开 http://127.0.0.1:5173 。首次使用由你自行创建用户名与密码；没有默认密码。开发入口仅监听本机。用户选择家中访问后，独立HTTPS入口与手机证书步骤见[家中访问](docs/home-access.md)。

现在无需 `.env` 或 AI 密钥即可使用默认 mock 模式。可从 `.env.example` 复制配置到被 Git 忽略的 `.env`。启用截图识别的配置见下方。密码、密钥不要发进聊天或写入前端。

数据库保存在 `data/runner.db`，私有图片在 `data/private/`；刷新及重启后保留，均不提交 Git。你在对话提供的个人背景仍保存在 `private/user-context.json`，没有自动填入正式档案。它是后续初始化参考资料，不会自动把未核对的图片读数当事实。

## 跑步课程与动态调整

在设置填写跑步基础、比赛目标、医生限制和身体情况，在日历保存可跑日期和时长。在记录页上传截图并核对确认，或手工记录跑步。身体反馈分别保存疲劳、肌肉酸胀、疼痛、疾病、活动影响与训练意愿，并可关联实际跑步。

AI 教练页面先评估能力和缺失事实，再生成七天草稿或完整比赛周期。一般七天模拟草稿只支持有限轻松安排；完整周期按历史训练基础约束跑量、长跑与受控跑，数据不足或症状限制时暂缓训练。单次突破不自动升级训练。生成后核对依据、日期与负荷变化，再确认整体更新；新事实使旧提案失效，历史版本保留。

力量相关 API 不再接受新记录，含力量的旧提案无法确认，历史含力量计划需重新生成跑步计划，不能恢复为执行安排。原数据不删除，可通过本机导出与备份留存。后面的日期验收记录反映当时版本，当前功能范围以本节及阶段文档最新记录为准。

## 启用 DeepSeek 截图识别

复制 `.env.example` 为 `.env`，在本机填写以下配置，然后重启后端（正在运行时先 Ctrl+C，再执行 `./scripts/dev.sh`）：

```dotenv
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=在本机填写你的密钥
AI_VISION_MODEL=deepseek-flash
AI_MONTHLY_BUDGET_CNY=20
```

密钥不发进聊天。现有 ChatGPT Plus 订阅不提供 DeepSeek API 额度。此配置启用截图和联合计划适配器；每次生成计划仍需勾选资料发送说明。教练对话已接入适配器，真实回答质量尚待验收。

打开「训练记录」→「选择截图」→检查区域预览、排除地图/账号→勾选发送说明→「开始识别所选区域」。每次请求只发送一段 JPEG，使用内联 Base64 和 `detail=original`，不创建公开图片链接。当前采用固定高度和重叠切片，视觉模块自动定位仍待真实样本调优。

页面按字段汇总冲突、校验问题和未知读数，可筛选基础记录、公里分段或其他指标，并搜索原始读数。每条读数保留模型原返回单位、标准单位、原图证据坐标和设备估计标签。相同量纲的明确别名（例如“分钟”与 minutes）统一显示，模型原返回单位保留；不同量纲及缺失单位仍提示问题，不自动换算。重复数值一致不代表识别准确；含校验问题、未知重复读数或单位冲突的字段不会自动填表。未完成全部分段时不能一键填表。用「将无冲突结果填入未填写字段」填表，不覆盖已有输入；日期或类型不明时留空，由你填写。点击「保存核对草稿」后，再「确认加入训练记录」。详细指标或整公里分段可点「核对 / 修正指标」，选择确认数值或不采用，填写标准数值和原图文字后保存这项核对；保留原读数及修改历史。整次训练确认时，当前证据下已确认的详细指标随基础记录保存，在训练记录中可展开查看。未核对、不采用和证据已变化的指标不加入正式记录，也不进入教练上下文。

识别任务每次由页面请求一个分段，数据库保存进度。关闭页面后不会继续后台识别；重新打开草稿可继续。成功分段缓存复用，失败只重试当前段（默认首次 + 2 次重试）。请求中断后等待租约超时即可继续；这类请求可能已计费，预留费用不会自动退回。预算统一按已核实的高峰价格保守估算，每次先原子预留，收到 usage 再结算；不是供应商实际账单或绝对扣费保证。

已在本机配置密钥，完成获授权的合成问答、联合计划及两张华为截图联调。截图结果已作为两条待核对草稿保存，没有确认成正式训练记录。严格人工基准仍有字段对应和证据待核对项，尚未通过完整准确性验收。

## 教练对话与合成联调

教练页面保存最近 50 次提问，显示模拟/AI 来源、回复状态及依据的事实修订号；资料变化后标记旧回复。真实模式发送前需同意发送问题、最近六次成功问答和页面列明的已保存资料。模型回答仅解释一般概念、已保存事实及需要核对的问题，不生成可执行安排；训练调整使用联合计划提案入口。结构校验和引用校验不代表专业训练质量或临床审阅。

同一请求 ID 的重复提交复用成功结果，处理中或失败时不会再次外发；更换问题需新 ID。失败可作为新问题重试，可能重新计费。网络结果未知时先刷新状态，不自动重试或退回预算预留。聊天文本仅作为未确认描述；新的身体情况先保存身体反馈，不自动转成健康事实。

以下脚本专用于已获授权的合成数据联调。密钥读取本机被忽略的 .env；脚本使用独立合成库，不取正式库资料。本机应用当前为 DeepSeek 模式，默认代码仍为 mock。运行：

```bash
backend/.venv/bin/python scripts/verify_deepseek.py
```

脚本只使用官方 DeepSeek 地址、独立 private/deepseek-smoke.db 和合成问题/档案（首次且未使用场景时为空），月预算最多 0.5 元（重复执行共用该库账本）。测试教练对话和待确认休息计划，不批准计划，不读取正式训练资料。结果保存在 private/deepseek-smoke-report.json；供应商账单仍以实际计费为准。已配置密钥，真实合成教练问答返回 200、七天休息提案返回 201，并通过引用及后端规则校验；未批准计划。初次计划因 4096 token 截断失败，随后出现未提供的证据编号，后端均拒绝；已提高教练输出上限至 8192 并明确引用白名单后重测通过。合成库累计预算占用 0.123164 元，非供应商实际账单。这次合成联调未发送个人资料。后续真实截图授权、结果及应用模式见下方记录；完整个人训练质量尚未验收。
